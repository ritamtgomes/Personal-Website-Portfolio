This is where I share my journey as an Aerospace Engineering student at Instituto Superior Técnico, along with some projects and notes as a tech enthusiast.

The website includes:
- **Projects** - My involvement in aviation, amateur radio, rocketry...

- **Contact & Social Media** - Ways to get in touch

## Tech Stack

Built with:

- HTML5, CSS, JavaScript
- Bootstrap Icons
- Google Fonts (Orbitron, Share Tech Mono)
